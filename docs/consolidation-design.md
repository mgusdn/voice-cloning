# 저장소 통합 설계

목표: `mgusdn/voice-cloning`을 음원 수집 → 데이터 준비 → GPT-SoVITS 학습/API → 음성 상담 챗봇의 단일 유지보수 저장소로 만든다.

## 확인된 구조와 선택

`testVoice` 데이터 도구와 `chatbot-voice`, `files` 런타임은 이미 이 저장소에 대부분 복사되어 있다. 별도 앱 네 개를 그대로 유지하는 방식은 중복을 남긴다. 새 저장소를 만드는 방식은 기존 이력과 위치를 바꾼다. 따라서 기존 `voice-cloning`의 전용 브랜치에서 중복을 정리한다.

- `chatbot/`: 기존 상담 상태·그래프를 보존하고 패키지 상대 import와 단일 CLI로 텍스트/STT/TTS 모드를 제공한다.
- `voice_clone/`: GPT-SoVITS HTTP 클라이언트와 파일 합성 CLI를 공유한다. 모델별 하드코딩과 외부 그래프 monkeypatch는 제거한다.
- `training/`: 기존 `files/`의 설치·슬라이싱·전사를 옮긴다. 모델 본체는 `training/GPT-SoVITS/`에 별도 설치한다.
- 루트 음원/데이터셋 도구를 보존한다. 참조 음성 도구는 입력/시간을 명시하는 CLI로 바꾼다.
- 240개의 기존 전사문은 보존한다. 오디오가 빠진 절대경로 목록과 반복 Colab 노트북은 공통 안내·목록 재생성 도구로 대체한다.
- GPT-SoVITS를 주 경로로 통일한다. 사용되지 않는 XTTS 요구사항, 개인 화자 전용 추론/데모, 별도 `chatbot-voice/`를 제거한다.

## 환경과 오류 처리

루트 `.env.example`에서 LLM/TTS 설정을 안내하며 환경변수 우선순위를 보장한다. 챗봇 텍스트 모드는 마이크 라이브러리 없이 실행할 수 있어야 한다. TTS는 설정 누락/서버 오류/전송 중단에도 텍스트 대화를 계속하고 불완전 파일을 남기지 않는다. 파일 합성 CLI는 실패 시 0이 아닌 종료 코드를 반환한다.

## 검증

네 저장소의 커밋을 기록하고 기능별 유지/대체/삭제 근거를 남긴다. unittest로 CLI/import, 스트림 중단, 슬라이스 길이, 절대경로 목록과 설정 우선순위를 검증한다. Python 컴파일과 shell 문법 검증, 경량 의존성 설치 후 CLI smoke test를 수행한다. 실제 모델/음성/키가 없으므로 유료 LLM 호출, 모델 다운로드, 실제 음질·학습은 실행 검증 범위에 포함하지 않는다.

원본 저장소 전체 삭제·이력 삭제는 이 통합 변경에 포함하지 않는다. 기존 작업은 원본 커밋으로 복구 가능하며 GitHub PR에서 변경을 검토할 수 있게 제공한다.
